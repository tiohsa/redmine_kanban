# システム設定

個人の表示設定はブラウザー（localStorage）に保存します。サーバーのリソース上限は環境変数で設定します。

## 環境変数によるサーバー保護設定

Redmine / Rails の起動時に、次の環境変数を指定します。

| 環境変数名 | デフォルト値 | 説明 |
| --- | --- | --- |
| `REDMINE_KANBAN_MAX_BOARD_ENTITIES` | `10000` | 1回のスナップショットで読み込み可能な最大チケット（エンティティ）数。上限を下げる場合に指定します（例: `5000`） |
| `REDMINE_KANBAN_MAX_BOARD_QUERIES` | `20` | スナップショット生成時に許可される最大 SQL クエリ数 |
| `REDMINE_KANBAN_MAX_TOTAL_BOARD_QUERIES` | `100` | スナップショット処理全体の最大 SQL クエリ数 |
| `REDMINE_KANBAN_MAX_RESPONSE_BYTES` | `8388608` (8 MiB) | 返却される JSON レスポンスの最大バイト数 |
| `REDMINE_KANBAN_PERF_LOG` | `0` | `1` を指定すると、スナップショット生成時の処理時間やクエリ数などの計測ログを出力します |

### 設定例（環境変数の指定）

Puma や Docker Compose などの環境変数定義に追加します：

```bash
# 最大チケット上限を 5,000 件に制限し、性能計測ログを有効化する例
REDMINE_KANBAN_MAX_BOARD_ENTITIES=5000
REDMINE_KANBAN_PERF_LOG=1
```

> [!WARNING]
> **最大エンティティ数の上限仕様**
> - 未設定、空文字、`0`、負の値、`10000` を超える値では、既定値の `10,000` を適用します。無制限にはできません。
> - この上限はサーバーの過負荷を防ぐためのもので、表示性能を保証する値ではありません。

---

## プラグイン設定画面が存在しない理由

Redmine の「管理」→「プラグイン」画面に本プラグインの設定リンクは存在しません。

スイムレーン、非表示ステータス、停滞検知、フォント、ダイアログサイズは、各ユーザーがボード上で設定します。設定はブラウザーに保存されます。
