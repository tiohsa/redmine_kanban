# はじめに

Redmine Kanban は、Redmine のチケットをカンバンボードで管理するプラグインです。

## プラグインの概要

チケット数やサブタスク階層が増えると、ボードの描画負荷も高くなります。

Redmine Kanban は HTML5 Canvas を使い、描画負荷を抑えています。

## 主な特徴

- **Canvas ベースの高速描画**: 大量のチケットが存在しても軽快にスクロール・操作可能。
- **停滞検知（Aging）**: 長期間更新されていないチケットを視覚的にハイライトし、ボトルネックの発生を防止。
- **スイムレーン切り替え**: 担当者別・優先度別・カテゴリ別・レーンなしの表示に対応。
- **ワークフロー準拠のドラッグ＆ドロップ**: Redmine のステータス遷移権限やワークフロー定義に完全準拠。
- **再帰的サブタスク管理**: 親チケット内でのインライン表示や個別カード展開、直接の完了チェック、一括作成に対応。
- **保存ビュー（Saved Views）**: フィルターや並び順、スイムレーン設定を用途ごとに名前を付けてローカル保存・即時切替。
- **作業時間タイマー（Work Timer）**: チケットの作業開始・停止を計測し、Redmine の作業時間記録へ直接反映。
- **柔軟な表示カスタマイズ**: フォントサイズ、カードのフィットモード、チケットダイアログの幅・高さ調整。

## 対応環境

| 項目 | サポート要件 |
| --- | --- |
| Redmine バージョン | Redmine 6.0 系列、6.1 系列、7.0 系列 |
| Ruby バージョン | 各 Redmine がサポートする Ruby バージョン（Ruby 3.1+ 推奨） |
| データベース | PostgreSQL, MySQL / MariaDB (Redmine 標準構成) |
| ブラウザー | Google Chrome, Mozilla Firefox, Microsoft Edge, Safari の最新版 |

## アーキテクチャの基本方針

データの整合性と性能を保つため、次の仕組みを採用しています。

1. **正規化された API v3 スナップショット**: チケット情報（`entities`）と階層（`tree`）を分けて送受信し、重複や循環参照を防ぎます。
2. **サーバーでの検証**: 更新・ステータス遷移・権限は Redmine サーバーで検証します。画面上の判定は操作の補助です。
3. **安全上限**: チケット数、SQL クエリ数、レスポンスサイズに上限を設け、サーバーを保護します。
