# トラブルシューティング

導入時や利用中によくある問題と対処法をまとめています。

## よくある問題と解決策

### 1. 「リソース上限を超過しました」または HTTP 422 エラーが表示される

**症状**: ボードを開いた際に 422 エラーが表示され、チケットが読み込まれない。

**原因**: 表示対象のチケット数（関連する親・子を含む）が上限を超えています。上限は既定で 10,000 件、または `REDMINE_KANBAN_MAX_BOARD_ENTITIES` の設定値です。

**対処法**:
- ツールバーのフィルター（プロジェクト、ステータス、トラッカー、担当者、期日）を使って、表示対象のスコープを絞り込んでください。
- サーバー管理者は、環境変数 `REDMINE_KANBAN_MAX_BOARD_ENTITIES` の設定を確認してください（最大 10,000 まで設定可能）。

---

### 2. カードをドラッグ＆ドロップしても元の列に戻ってしまう

**症状**: カードをドロップした直後、元のステータス列やレーンに戻る。

**原因**:
1. **Redmine のワークフロー制約**: 移動先のステータスへの遷移が、Redmine の「管理」→「ワークフロー」で許可されていません。
2. **カテゴリレーン間移動**: 異なるカテゴリのレーンへは移動できません。
3. **権限不足**: ユーザーに「チケットの編集」または「Kanbanの管理」権限がありません。

**対処法**:
- Redmine 管理者にワークフロー設定（ロール、トラッカーごとの許可ステータス）を確認してもらってください。
- チケットのカテゴリを変更したい場合は、カードをクリックして編集ダイアログから手動で変更してください。

---

### 3. ボードが白画面になる、またはスタイルが崩れる

**症状**: ボードを開いても画面が表示されない、またはボタンやレイアウトが崩れている。

**原因**: プラグインのインストール後または更新後に、フロントエンドのアセットが正しくビルドされていません。

**対処法**:
プラグインの `frontend/` ディレクトリでビルドを実行し、Redmine を再起動してください。

```bash
cd plugins/redmine_kanban/frontend
pnpm install
pnpm run build
touch ../../../tmp/restart.txt
```

---

### 4. 保存ビューが別の端末やブラウザーに引き継がれない

**症状**: 自宅の PC や別のブラウザーで開いた際に、職場で作成した保存ビューが表示されない。

**原因**: 保存ビューは各ブラウザーの localStorage に保存され、別の端末やブラウザーには同期されません。

**対処法**:
利用する端末やブラウザーで、保存ビューを作り直してください。

---

### 5. 一括子チケット作成が失敗する

**症状**: 一括子チケット作成を実行するとエラーになる。

**原因**:
- **50件超過**: 1回のリクエストで送信できるサブタスクは最大 50 件です。51件以上の場合は登録できません。
- **トラッカーの不一致**: 選択されたトラッカーが、対象プロジェクトで利用可能になっていません。

**対処法**:
サブタスクを 50 件以内に小分けにして作成するか、プロジェクトの設定で該当トラッカーを有効化してください。
