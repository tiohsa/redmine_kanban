# フィルターと表示制御

ツールバーのフィルターで、表示するチケットを絞り込めます。

## 利用可能なフィルター項目

ツールバーには以下のフィルターが配置されています：

| フィルター項目 | 説明 |
| --- | --- |
| **プロジェクト（Project）** | 現在のプロジェクト、サブプロジェクト、または閲覧権限のある他プロジェクトを選択して複合表示 |
| **ステータス（Status）** | 表示するステータス列を個別に選択。不要な列を非表示にしてボードをすっきり整理 |
| **トラッカー（Tracker）** | バグ、機能、タスクなど、特定のトラッカーに属するチケットのみを抽出 |
| **担当者（Assignee）** | 特定のユーザーまたはグループが担当しているチケットを抽出（「未アサイン」指定も可能） |
| **期日（Due Date）** | 期限切れ、今日が期日、今週中、指定日数以内などの条件で絞り込み |
| **優先度（Priority）** | 高め、急、今すぐ等の特定優先度のチケットを抽出 |
| **キーワード検索（Subject / ID）** | チケットの件名やチケット番号によるインクリメンタル検索 |

---

## サーバー側絞り込みとクライアント側表示制御

フィルターは、階層を保ちながらサーバーとブラウザーの 2 段階で適用します。

### 1. サーバー側の一次絞り込み（Primary Membership）
- サーバーで、プロジェクト・ステータス・トラッカー・担当者・期日・優先度などの条件に合うチケットを抽出します。
- **階層の保持**: 必要な親・祖先チケットや関連サブツリーも取得し、階層が途切れないようにします。

### 2. クライアント側の最終表示制御
- ブラウザーで取得データに同じ条件を適用し、表示するカードを決めます。
- フィルターや「非表示ステータス」で親の列が隠れていても、表示条件に合う子チケットは独立したカードとして表示します。

---

## メタデータの取得と候補リスト

担当者・トラッカーの候補は、プロジェクトの選択に応じて `GET /projects/:project_id/kanban/metadata` から取得します。

候補の件数は最大 10,000 件に制限されており、プロジェクトの権限を持つユーザーやトラッカーのみが安全に一覧表示されます。
