# 保存ビュー（Saved Views）

フィルター・並び順・スイムレーンを**保存ビュー**として保存し、ワンクリックで呼び出せます。朝会用や自分の担当分など、用途別に作成できます。

## 保存ビューの主な操作

ツールバーの「保存ビュー」メニューから以下の操作が行えます：

- **新規保存（Save as new view）**: 現在設定されているフィルター・並び順・レーン設定に名前を付けて保存します。
- **適用（Apply）**: 一覧からビューを選択すると、保存されていた条件がボードへ即座に反映されます。
- **上書き保存（Overwrite）**: 条件を変更した後、現在のビューに上書きして更新します。
- **名称変更（Rename）**: ビューの名前を変更します。
- **削除（Delete）**: 不要になったビューを削除します。削除しても現在の表示条件はそのまま維持されます。

### 「変更あり（Modified）」の表示

ビューの適用後にフィルターや並び順を変更すると、名前の横に **Modified（変更あり）** と表示されます。
明示的に「上書き保存」を行わない限り、元の保存内容は書き換わりません。

## 保存される項目と除外される項目

保存ビューには、表示対象と並び順を保存します。画面レイアウトや端末ごとの表示設定は含みません。

| 保存される項目（ビュー固有） | 除外される項目（個人・端末設定） |
| --- | --- |
| 選択されたプロジェクト | フォントサイズ（13px等） |
| ステータスフィルター・非表示ステータス列 | フルスクリーンモード |
| トラッカー、担当者、優先度、期日フィルター | フィットモード（均等幅 / 固定幅） |
| キーワード検索条件 | カード表示モード（標準 / コンパクト） |
| ソート順（並び順ルール） | サブタスクの表示モード |
| スイムレーンの種類（担当者、優先度等） | 停滞検知（Aging）の閾値 |
| 他プロジェクト閲覧許可スイッチ | チケットダイアログのサイズ設定 |
| | 作業時間タイマーの計測状態 |

## データの保存先と仕様

> [!NOTE]
> **ローカルストレージ（localStorage）によるクライアント保存**
> - 保存ビューはサーバーのデータベースではなく、お使いのブラウザーの `localStorage` に保存されます。
> - 保存先は Redmine インスタンス・プロジェクト・ログインユーザーごとに分かれます。キー形式は `rk_saved_views:<Redmineサブパス>/projects/<プロジェクトID>/kanban:user:<ユーザーID>` です。
> - 1つのスコープあたり最大 20 件までビューを保存できます。
> - ビュー名は 1 〜 80 文字で、スコープ内で一意である必要があります。
> - 最後に適用したビューは、次回ボードを開くと復元されます。ビュー ID は末尾が `:active` の別キーに保存されます。
