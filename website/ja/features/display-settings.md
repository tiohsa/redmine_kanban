# 表示設定・ダイアログ

ボードの表示密度や文字サイズ、チケットダイアログのサイズを調整できます。

## 表示設定メニュー

ツールバーの歯車アイコン（表示設定）をクリックすると、設定ポップオーバーが開きます。

![Redmine Kanban の表示設定ダイアログ。フォントサイズやダイアログサイズなどの調整項目が並ぶ。](/images/display-settings-ja.png)

[画像を拡大](/images/display-settings-ja.png)

### 1. カラーテーマ（Color Theme）

カンバンボードの配色テーマを切り替えます。

- **ライト（Light）**: 標準の明るい配色です（デフォルト）。
- **ダーク（Dark）**: 暗い背景と視認性を最適化したダークモード配色です。Canvas 描画のカード、ヘッダー、バッジ、ツールバー、各ポップオーバーがダークトーンに切り替わります。

#### 特徴と動作
- **即座に反映**: ページの再読み込みなしで即時にテーマが切り替わります。
- **ユーザー・インスタンスごとの保存**: 設定はブラウザーのローカルストレージにユーザーごと・Redmine インスタンスごとに保存され、次回アクセス時も維持されます。
- **Redmine 本体テーマとの連携**: Redmine Kanban のカラーテーマはカンバン領域を独立して描画します。チケット編集・詳細ダイアログ（iframe）は Redmine 本体の CSS テーマを引き継ぎ、Redmine 本体にダークテーマ（例: 外部プラグインやカスタムテーマ）が適用されている場合でもカンバン側の強制背景色に邪魔されず自然に表示されます。

### 2. ボードの表示調整

- **カード表示モード**:
  - **標準（Standard）**: 担当者アバター、トラッカー名、優先度、期日、進捗率、サブタスクなどを詳細に表示。
  - **コンパクト（Compact）**: 表示情報を件名とステータス等に絞り込み、画面内により多くのカードを並べて表示。
- **フィットモード（Fit to Screen）**:
  - オン: ブラウザーの横幅に合わせて全ステータス列が画面内に収まるように均等伸縮します。
  - オフ: 各列が読みやすい固定幅となり、列数が多い場合は横スクロールで閲覧します。
- **フォントサイズ調整**:
  - ボード全体の文字サイズを 11px 〜 16px の範囲で切り替え可能です（デフォルトは 13px）。

## チケットダイアログのサイズ調整（Ticket Dialog Size）

チケットの表示・編集・新規作成に使うダイアログのサイズを調整できます。

![チケットダイアログの幅・高さ・全画面設定コントロール。](/images/issue-dialog-settings-ja.png)

[画像を拡大](/images/issue-dialog-settings-ja.png)

| 設定項目 | 選択肢 / 動作 | デフォルト値 |
| --- | --- | --- |
| **幅（Width）** | `900px`, `1200px`, `1500px` | `1200px` |
| **高さ（Height）** | `自動（Automatic）` または `50%` 〜 `90%`（画面高に対する比率） | `自動` |
| **全画面表示（Fill viewport）** | 画面いっぱいにダイアログを拡大するトグル | `オフ` |
| **サイズのリセット（Reset size）** | 幅 1200px、高さ自動、全画面オフの既定値に戻す | - |

### ダイアログ設定の特徴
- **ブラウザー単位・全プロジェクト共通**: 設定はブラウザー（localStorage）に保存され、全プロジェクトの表示・編集・作成ダイアログに適用されます。
- **広い画面で編集**: 大きなディスプレイや、カスタムフィールドが多いチケットでは、幅や高さを広げると編集しやすくなります。
