# Display Settings

Adjust board density, font size, and issue dialog dimensions.

## Display Settings Popover

Click the gear icon on the board toolbar to configure layout preferences.

![Redmine Kanban display settings popover showing font size and dialog size controls.](/images/display-settings-en.png)

[Enlarge image](/images/display-settings-en.png)

### 1. Board Layout Preferences

- **Card Display Mode**:
  - **Standard**: Displays complete issue details including avatar, tracker, priority, due date, progress ratio, and subtasks.
  - **Compact**: Shows condensed cards focusing on subject and status, fitting more cards simultaneously.
- **Fit Mode (Fit to Screen)**:
  - Enabled: Fits all active status columns evenly inside the viewport.
  - Disabled: Columns maintain standard comfortable widths, scrolling horizontally when necessary.
- **Font Size**:
  - Adjust typography across headers and cards from 11px to 16px (default: 13px).

## Ticket Dialog Sizing

Set the dialog size for viewing, editing, and creating issues:

![Ticket dialog width, height, and fullscreen controls.](/images/issue-dialog-settings-en.png)

[Enlarge image](/images/issue-dialog-settings-en.png)

| Setting | Options | Default |
| --- | --- | --- |
| **Width** | `900px`, `1200px`, `1500px` | `1200px` |
| **Height** | `Automatic` or `50%` to `90%` of viewport height | `Automatic` |
| **Fill Viewport** | Toggle to expand the modal to fill the browser window | `Off` |
| **Reset Size** | Restores default dimensions (1200px, Auto height, Fill off) | - |

### Sizing Features
- **Cross-Project Browser Persistence**: Saved per user in browser local storage and applied across all projects and boards.
- **More Editing Space**: Increase width or height when using a large display or editing issues with many custom fields.
